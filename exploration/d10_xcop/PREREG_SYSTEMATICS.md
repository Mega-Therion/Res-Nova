# Pre-registration: X-COP R₂₀₀ systematics sweep, one at a time (2026-11-19, before any number)
Baseline is Test C (full-field x_H screen, x_H,low = 154, supply cap): R₂₀₀ = 0.755, 8/12.

One systematic varied at a time, each within its physical range. Nothing is tuned: every configuration is reported.
1. Inner gas core r_c/R₅₀₀ = 0.05 and 0.2 (baseline 0.1).
2. Total mass = M_HSE (no non-thermal correction) instead of M_tot.
3. Boundary r_b = 1.2 r_v. This is the largest shift that stays inside the Lane–Emden radius π/μ = 3.1 Mpc for all clusters (§14). Larger values break the boundary-value problem.

**Decision.**
- The R₂₀₀ gap is called **systematics-limited** if the baseline plus all four variants span the pass criterion (median ∈ [0.8, 1.25] with ≥ 9/12) for at least one physically allowed configuration, and **not closed** otherwise.
- Either way, D10 is not declared closed unless the baseline itself passes.
