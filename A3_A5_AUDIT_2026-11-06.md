# A3 and A5 content audit — 2026-11-06

Companion to `A2_AUDIT_2026-11-06.md`. That audit established that A2 as
formalized is vacuous. This one applies the same test to A3 and A5 and finds a
different defect in each. Everything below is `[P]` about the formal text in
`AXIOMS_V2.lean`, not a physics claim.

Kernel: Lean 4 core only, no Mathlib, so the file re-runs without the pinned
dependency. Re-run 2026-11-06: exit 0, five theorems, zero `sorry`, axiom
footprints `[propext, Quot.sound]` (plus `Classical.choice` where a choice is
needed). The receipt is the `#print axioms` block at the foot of the file.

## A3 is vacuous

Stated in prose as: the vacuum locally extremizes entanglement entropy at fixed
boundary volume.

Formalized as (`AXIOMS_V2.lean`, `Axiom_A3_Equilibrium`):

```
maximal_vacuum_entanglement : ∀ (_V : Set Q), ∃ (S_max : ℝ), S_max ≥ 0
```

The field quantifies over a set and a real, but constrains the real only to be
non-negative. Taking `S_max = 0` satisfies it. There is no reference to entropy,
to a vacuum, to an extremum, or to the set `V`, which is bound and unused.

**Theorem `a3_holds_for_every_carrier`**: `A3Shape Q` is inhabited for *every*
type `Q`. Not merely satisfiable — constructed uniformly, so A3 excludes
nothing.

**Theorem `a3_admits_no_extremum`**: it holds even on `Empty`, a carrier with
no states at all. A statement true of the empty carrier cannot describe a
vacuum.

A3 therefore does no independent work. It should not be described as an
equilibrium axiom in any manuscript until it is rewritten to mention entropy.

## A5 is redundant, not vacuous

Stated in prose as: the field equations asymptotically recover GR in the strong
field and Newtonian gravity in the weak-field high-acceleration limit.

Formalized as (`Axiom_A5_Recovery`):

```
newtonian_limit : ∀ ε > 0, ∃ K > 0, ∀ x, x > K → |μ x - 1| < ε
```

That is character-for-character the third conjunct of
`IsInterpolationFunction` (`AXIOMS_V2.lean:38`), which A4 imports through
`closure_is_interpolation`.

**Theorem `a5_derived_from_a4`**: `A4Shape μ → A5Shape μ`, supplied verbatim by
`h.closure_is_interpolation.2.2`.

So A5 is a theorem of A4. Assuming it adds no constraint, and the five-axiom
set is really four. This is a bookkeeping defect rather than a soundness
defect: nothing false is asserted, but the axiom count overstates the content.

Fidelity note: `A4Shape` here omits `weak_field_balance`, because `Real.sqrt` is
not available in core Lean. Omitting a conjunct weakens the hypothesis, so the
implication holds a fortiori for the full A4 class. The derivation is therefore
conservative in the safe direction.

The strong-field half of A5 (GR recovery) is not formalized at all and is not
addressed by this audit.

## What the axiom set actually contains

| Axiom | Status after audit |
|---|---|
| A1 substrate | carries content; not satisfiable on every carrier (zero space has no unit vector). Not audited here: needs Mathlib classes. |
| A2 entanglement geometry | vacuous as formalized (`A2_AUDIT_2026-11-06.md`); repair `A2Strong` proposed and checked non-vacuous. |
| A3 equilibrium | vacuous as formalized; holds on every carrier including `Empty`. |
| A4 variational closure | carries content; `a4_not_vacuous` witnesses the constant `0` failing the first conjunct. |
| A5 recovery | theorem of A4, not independent. |

The set that does independent work is {A1, A4}. A2 and A3 need rewriting before
they can be cited; A5 needs demoting from axiom to derived proposition.

## Kill criteria for the repairs

- **A3 repaired** must mention a functional on states and an extremum condition,
  and must fail on at least one explicit carrier. Until a candidate repair
  excludes something, it has not been tested.
- **A5** leaves the axiom list. It survives only as a lemma derived from A4, and
  the strong-field half remains `[O]` until formalized.
