# A2 is vacuous as formalized — audit and repair proposal (2026-11-06)

**Author:** Vesper (Base44 Superagent), reconciler run
**Tier:** `[P]` for the five audit theorems and the three repair theorems, all
kernel-checked in this environment. `[O]` for the physics content of A2.
**Status of A2 itself:** unchanged in `AXIOMS_V2.lean`. This file does not edit
the axiom; it measures it and proposes a replacement for RY to adopt.

## 1. The problem

`05_lean_formalization/AXIOMS_V2.lean` states A2 in prose as *"spacetime
distance is a monotone functional of quantum relative entropy"* and formalizes

```lean
class Axiom_A2_EntanglementGeometry (M : Type*) [MetricSpace M] (Q : Type*)
    [NormedAddCommGroup Q] [InnerProductSpace ℂ Q] : Prop where
  geometric_emergence : ∃ (dist : M → M → ℝ), ∀ x y : M, dist x y ≥ 0
```

`THEORY_ASSUMPTION_AUDIT.md:28` already recorded that this is "satisfied by
`dist ≡ 0`" and that it constrains nothing. That finding was written, and then
A2 was never repaired. This run closes that gap: the vacuity is now proven, not
asserted, and a repair is proposed.

Two independent failures, both kernel-checked here:

1. **`dist ≡ 0` satisfies A2.** Any non-negative function does.
2. **Every non-negative asymmetric function satisfies A2.** This matters
   because quantum relative entropy `S(ρ‖σ)` is *not* symmetric, and A2 claims
   distance is a monotone functional of it. A monotone functional of an
   asymmetric divergence is not a metric. Symmetrization is a separate step
   that A2 does not supply.

Consequence: A2 as written implies no symmetry, no identity of indiscernibles,
and no triangle inequality. It does not define a geometry. It asserts that
*1.5* one non-negative two-argument function on `M` exists, which is true of
any nonempty `M`.

    git grep Axiom_A2 across main: one declaration, two mentions in audit and
    ledger files, zero consumers. The axiom is unused by every theorem in the
    tree.

## 3. The repair

`A2RepairProposal.lean` states a three-conjunct replacement:

```lean
structure A2Strong (dist : M → M → Rat) : Prop where
  nonneg    : ∀ x y, dist x y ≥ 0
  refl_zero : ∀ x y, dist x y = 0 → x = y
  symm      : ∀ x y, dist x y = dist y x
```

Proven about it:

| Theorem | Statement | Axioms |
|---|---|---|
| `zero_excluded` | `dist ≡ 0` fails `A2Strong` on any two-point carrier | propext, Quot.sound |
| `asymmetric_excluded` | an asymmetric divergence fails `A2Strong` | propext, Quot.sound |
| `repair_satisfiable` | the discrete metric on `Bool` satisfies `A2Strong` | propext, Quot.sound |

The third line is the one that matters: a repair that excluded everything would
be worthless. The repaired axiom is non-vacuous and satisfiable.

## 4. What the repair still does not do, stated honestly

`A2Strong` is a **metric** axiom, not an *entanglement* axiom. It fixes failure
2 and failure 1, and it still does not formalize the physics sentence
"monotone functional of relative entropy." Doing that needs an actual von
Neumann entropy and relative entropy on the substrate `Q`, which needs Mathlib
(`VonNeumannEntropy`) plus a monotonicity proof under a chosen partial order on
states. That is a real module, not a patch, and this environment has no Mathlib
pin (`lean` here is 4.35.0 standalone; the package pins Mathlib at
`5eec30bc`).

So the honest tier split:

- A2's *vacuity* is now `[P]`. It is proven.
- A2's *repair* is `[P]` as a metric axiom.
- A2's *physics claim* stays `[O]`, and stays `[O]` on purpose. No amount of
  metric structure gives you "distance is a functional of relative entropy."
  That sentence either becomes a definition with a named entropy and a
  monotonicity theorem, or it comes out of the axiom list and goes into the
  motivational annex.

**Kill criterion for the physics reading:** if no monotone functional of
relative entropy exists that satisfies `A2Strong` on the substrate used by A1,
the entanglement-geometry reading is dead and A2 reduces to "spacetime is a
metric space," which is not a Chyren result.

## 5. Placement and gate status

These files live in `05_lean_formalization/audits_2026-11-06/`, deliberately
**not** in the gated module list. `check_target_inventory.py` globs
`ROOT.glob("*.lean")` non-recursively, and `verify_all_proofs.sh` has an
explicit `TARGETS` list, so a subdirectory is invisible to both. That is a
deliberate scoping statement, not an attempt to dodge scrutiny: these modules
cannot join the gate until a toolchain with the pinned Mathlib builds them, and
they were checked here with standalone core Lean instead.

Promoting them to gate targets requires: moving both files up one level, adding
both to `lakefile.lean` `roots`, adding both to `verify_all_proofs.sh`
`TARGETS`, and a green `lean-gate` run. Not done here.

## 6. Recommendation to RY

Adopt `A2Strong` and stop describing A2 as entanglement geometry until a real
relative-entropy module exists. The current label overclaims in the direction
the whole audit cycle has been trying to eliminate: it is the one axiom in the
set whose *name* is doing all the work.
