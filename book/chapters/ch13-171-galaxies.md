# Chapter 13: 171 Galaxies

A theory is only as good as its agreement with data. The interpolation function that carries a modified-gravity theory from the Newtonian regime to the deep-acceleration regime may be mathematically elegant, and the acceleration scale may be tantalizingly close to the horizon value, but none of that matters if the theory cannot predict what galaxies actually do — and it matters even less if the function itself does not survive the solar system, where gravity has been tested to extraordinary precision for over a century. The test is empirical, and the data is the SPARC database — Spitzer Photometry and Accurate Rotation Curves — a collection of 175 disk galaxies with 3,391 measured kinematic data points, each one a star or gas cloud orbiting the center of its galaxy at a speed that Newton's gravity cannot explain.

The Res Nova team — which is to say, Ryan Yett, working as an independent researcher — ran the theory against the full SPARC database. The process was rigorous: the raw data was cryptographically authenticated (SHA-256 hashes were recorded), the analysis scripts were documented, and the results were recorded in a structured JSON format that could be audited and reproduced. The measurement used 171 galaxies and 3,375 data points, with bootstrap resampling performed over galaxies (not over individual data points, which would have falsely inflated the precision).

The result: a₀ = (1.116 ± 0.128_stat ± 0.097_syst) × 10⁻¹⁰ m/s², with a total uncertainty of 14.4%. This is the acceleration scale at which gravity transitions from Newtonian to modified. It is the number that determines, for every galaxy in the universe, where the rotation curve stops declining and goes flat. This measurement comes from the shape of the rotation curves themselves, not from any particular choice of interpolation function between the Newtonian and deep-MOND regimes — but a full re-derivation under the corrected function below has not yet been carried out, and this chapter will not claim more certainty about that number than currently exists.

## A correction, made in the open

Between the writing of this chapter's first draft and its final one, the theory's interpolation function failed a test it should never have been allowed near a galaxy fit without passing first: the solar system. The function used in that first draft, μ_dual(x) = x/(1+x), was checked against the same regime where Newtonian gravity is tested to exquisite precision — the precession of Mercury's orbit — and it failed, badly. The excess it predicts in the solar system is not a rounding error or a marginal tension; it overshoots the observational bound by many orders of magnitude. A theory whose interpolation function cannot pass through the solar system without producing an anomaly that large is not a viable theory of gravity, whatever it does with galaxies. This was found independently of the galaxy work — a separate line of investigation, aimed at closing the gap between the galactic and relativistic regimes, that turned up a defect the galaxy fits alone would never have exposed.

There is a second, more embarrassing complication attached to the same discovery. The comparison this chapter originally reported — "GOD" against MOND, framed as one model with a derived interpolation function competing against another model with a chosen one — was never actually testing that distinction. The code that produced the original numbers implemented only one interpolation function for both cases. Whatever the original result meant, it did not mean what the chapter said it meant.

Both problems point to the same fix: replace μ_dual(x) = x/(1+x) with μ_std(x) = x/√(1+x²) everywhere in this theory, galaxies included. μ_std passes the solar-system test with a wide margin. It is also, and this matters for what follows, the same interpolation function used by standard MOND. Once both models run on the same function, there is no longer a meaningful sense in which "GOD" and "MOND" are different galaxy models at all — the entire comparison reduces to one question: which value of a₀, the horizon-derived one or the literature-fitted one, better matches the data.

## What the corrected numbers say

Under μ_std, the zero-free-parameter tier-0 comparison flips. The horizon-derived a₀ produces a median reduced χ² of 11.077 per galaxy. MOND's fitted a₀, run through the identical function, produces 9.935. MOND fits better. The headline this chapter originally carried — GOD beats MOND at zero parameters — is false under the corrected function. It was an artifact of comparing two different functions under two different names, not a finding about which acceleration scale nature prefers.

The tier-1 comparison, where individual galaxy mass-to-light ratios are allowed to float, is less dramatic: horizon a₀ gives 3.360, fitted a₀ gives 3.412 — close to a tie, similar in spirit to what the earlier draft reported at this tier, though the exact numbers have moved. Neither model is meaningfully better here once nuisance parameters absorb the freedom that a₀'s choice used to carry.

The comparison against standard dark matter halos is untouched by any of this. NFW models with cosmological priors still return χ² = 5.62 at 716 parameters; NFW with free concentration still returns χ² = 1.92, with 97 of 171 galaxies pinned at the boundary of their concentration prior. That part of the story used a halo model with no interpolation function in it at all, so the μ correction does not touch it one way or the other.

## What is left standing, and what is not

The honest version of the parsimony argument survives in a narrower form than before. a₀ is still either derived from the horizon or fitted from the data — that structural difference between the two approaches to gravity has not changed, and if the horizon derivation is correct, it is still a theory with one fewer free number than MOND. But "parsimony" is not the same claim as "fits better," and this chapter conflated the two. Under the corrected function, the fitted value wins the fit. Whether a physically motivated zero-parameter scale that fits slightly worse than a number tuned to the data is the more interesting result is a judgment call, not a victory — and it is a much smaller claim than "the GOD model fits better."

What is not left standing is the specific comparison this chapter used to build its case: two supposedly distinct interpolation functions, one derived and one chosen, disagreeing on 171 galaxies in the derived model's favor. That comparison did not exist. There was one function wearing two names, and when it was replaced with the function that actually survives the solar system, the theory that was supposed to be winning stopped winning.

This is what science looks like when it is done with intellectual integrity — not only in the reporting of a result, but in the willingness to take a result back once it is found to rest on a mistake. Not declarations of victory, but honest assessments of what is known and what is not. That standard does not bend for a result that was flattering while it lasted. It applies exactly as hard here, to a chapter that got it wrong, as it applies anywhere else in this corpus.
