## The first three program gates

1. **Reproduce the foundations.** Establish the clean-clone SPARC fetch/checksum route and cold-run Lean CI gate before presenting new analysis.
2. **Pre-register before fitting.** Freeze data release, competing models, priors, diagnostics, and failure conditions for the galaxy inference work.
3. **Map failures as carefully as successes.** Build a covariant-branch constraint atlas that separates allowed, excluded, and unresolved regions under explicit assumptions.

## Public description

> **Res-Nova is an open, falsification-first research program studying whether a dual-channel galaxy-dynamics interpolation admits a stable relativistic completion consistent with local gravity, gravitational waves, lensing, and cosmology. Formal identities, empirical measurements, cited constraints, and open hypotheses are maintained in separate auditable ledgers.**

This description must not be shortened into a claim that Res-Nova has replaced ΛCDM, derived the MOND scale, or solved dark matter/dark energy. Those statements remain outside the program’s present evidence boundary.
